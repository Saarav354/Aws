How this page reached you

  1. Your browser asked for this page over HTTPS.
  2. CloudFront answered from the edge location nearest to you.
  3. If the edge did not have a copy yet, CloudFront fetched it from S3 using a signed request (Origin Access Control).
  4. The S3 bucket stays private - nobody can read it directly.
